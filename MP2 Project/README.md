## What is trendar?

**trendar** (a play on *trend* + *radar*) is a web app that helps you name the design style behind an image you love. Upload a reference image and get matched to the **top 2–3 design trends** from a curated library, each with defining traits and related example images.

You can also **browse the full gallery** and **filter by trend** to explore styles without uploading anything.

A small extra: the **landing page theme changes based on the day** you visit (and you can pick a day theme if you prefer).

---

## Who is it for?

**trendar** is for anyone looking for design inspiration — especially **design students and designers** working on moodboards or UI references.

If you’ve ever scrolled Pinterest, found an image you love, and thought *“I want more like this — but I don’t know what this style is called”* — **trendar** is for you. Instead of guessing search terms and hoping the algorithm cooperates, you upload the image and get named trends plus examples to explore further.

---

## How to use it

No install required — **trendar** runs entirely in the browser.

1. Open **[https://trendar.bolt.host/](https://trendar.bolt.host/)**
2. **Upload** a reference image (drag-and-drop or file picker)
3. View your **top 2–3 trend matches** with traits and example images
4. Or go to **Gallery** to browse all curated images and filter by trend

**Best on desktop.** Mobile support is limited — full responsiveness is planned for a future update.
